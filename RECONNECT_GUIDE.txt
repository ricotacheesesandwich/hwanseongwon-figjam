[공동 사건 조사 보드 - 새 폴더로 갈아끼우기]

이 패키지는 기존 Supabase 프로젝트를 그대로 사용합니다.
DB, Storage, Secrets, 관리자 비밀번호를 다시 만들 필요가 없습니다.

1. 기존 realtime-investigation-board 폴더는 삭제하지 말고 이름을
   realtime-investigation-board-old 로 바꿔 백업합니다.

2. 이 ZIP을 새 폴더에 압축 해제합니다.
   폴더 이름은 realtime-investigation-board 로 두면 됩니다.

3. VS Code에서 새 폴더를 엽니다.

4. 터미널에서 아래를 실행합니다.
   npm install

5. 그 다음 실행합니다.
   npx serve .

6. 터미널에 표시되는 localhost 주소를 엽니다.

7. 기존에 설정한 관리자 비밀번호로 로그인합니다.

현재 연결 대상:
- Supabase Project URL: https://uaetlweizsdeoqearrlt.supabase.co
- Edge Function 실제 slug: clever-api
- Board ID: main-investigation-board
- Storage bucket: investigation-board-files

중요:
- PASSWORD_PEPPER와 BOOTSTRAP_ADMIN_SECRET은 Supabase 서버 Secrets에 이미 있으므로 로컬 파일에 넣지 않습니다.
- 관리자 비밀번호 bootstrap도 이미 끝났으므로 다시 실행하지 않습니다.
- Supabase SQL schema도 이미 실행했으므로 다시 실행하지 않습니다.
- 로컬 supabase/functions/clever-api/index.ts는 서버 코드 보관용입니다.

나중에 Edge Function을 CLI로 다시 배포할 때는 link 없이 아래처럼 직접 프로젝트를 지정할 수 있습니다.
  npx supabase functions deploy clever-api --project-ref uaetlweizsdeoqearrlt --no-verify-jwt
